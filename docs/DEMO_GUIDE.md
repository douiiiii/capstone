# 발표자 시연 가이드

> 화성시 AI 시민리더 허브 — 발표 당일 그대로 사용하는 가이드.
> 5분/10분/15분 버전을 분기 가능하도록 구성.

---

## 0. 사전 체크리스트 (시연 30분 전)

```sh
# 1) 가상환경 활성화
source .venv/bin/activate

# 2) DB 연결 정상 확인
python -c "from app import create_app; create_app('development').app_context().push()"

# 3) 테스트 일괄 통과 확인 (195개)
pytest -q

# 4) 시연 스크립트 사전 리허설
python scripts/demo_scenarios.py
```

✅ 위 4개가 모두 OK 면 시연 준비 완료.

> ⚠️ **주의** — Supabase 가 콜드 스타트되어 첫 요청이 느릴 수 있다.
> 발표 시작 5분 전 한 번 `python scripts/demo_scenarios.py --only 1` 으로 워밍업.

## 2. 각 시나리오별 강조 포인트

### ① 일반 매칭 — "점수가 왜 그렇게 나왔는지 다 설명할 수 있다"
- 💬 *"권역 40 + 분야 40 + 시간 20 = 100점이 기본인데, 여기에 평점/만족도/상성까지 누적돼서 종합 점수가 나옵니다."*
- 💡 강조 키워드: **투명성, 설명 가능성, breakdown**
- 화면에 보여줄 필드: `breakdown.base`, `breakdown.bonuses`, `breakdown.penalties`

### ② 정기 강의 — "매칭은 1건인데 강의는 16개"
- 💬 *"학교에서 '주 1회 4개월' 요청하면, 시스템이 16개의 강의 세션을 미리 잡습니다."*
- 💡 강조 키워드: **세션 분해, 충돌 검사, 부하 정확도**
- 화면에 보여줄 출력: 일정 5개 + "외 11개"

### ③ 부하 분산 — "한 명에게 일이 몰리지 않는다"
- 💬 *"이번 달 80% 채운 강사는 -15점, 가장 많이 매칭된 강사는 -10점 추가. 한도 넘으면 아예 후보에서 빠집니다."*
- 💡 강조 키워드: **공정성, 자동 제외, 쏠림 방지**

### ④ 상성 시스템 — "단순 점수가 아닌 '궁합'까지 본다"
- 💬 *"이 강사가 복지관에서 평균 만족도 4.5 이상이면 +15점. '학교는 안 하고 싶다'고 등록한 강사가 학교 요청에 매칭되면 -5점."*
- 💡 강조 키워드: **상성, 선호도, 만족도 누적**

### ⑤ 신규 강사 6번째 슬롯 — "신입한테도 기회를 준다"
- 💬 *"Top 5 외에 신규 강사 1명을 강제로 더 노출합니다. 누적 강의가 10회 미만이어도 권역만 맞으면 무조건 보여줘요."*
- 💡 강조 키워드: **공정성, 콜드스타트 해결, 6번째 슬롯**

### ⑥ 자동 조건 완화 — "매칭 실패 0건"
- 💬 *"정확히 일치하는 강사가 없으면 → 인접 권역 → 유사 분야 → 조건 완화 → 그래도 없으면 평점 상위 3명. 그 결과 매칭률 100%."*
- 💡 강조 키워드: **fallback, 매칭률 100%, 실패 원인 분석**

## 3. 자주 받을 질문 + 답변 예시

### Q1. "이게 ML(머신러닝)인가요?"
**A.** 현재 v4.8은 **룰 기반(rule_based_v4)** 입니다. 단, ML 전환을 미리 준비해서
매칭이 일어날 때마다 추천 후보 전체에 대해 피처 스냅샷 + 라벨(선택/진행/만족도)을
`MLTrainingLog` 테이블에 적재하고 있습니다.
약 500건의 라벨이 쌓이면 XGBoost 같은 모델로 전환할 계획입니다 (`GET /api/ml/status` 에서 진척도 확인 가능).

### Q2. "왜 100점 만점인가요? 가중치 어떻게 정했나요?"
**A.** 화성시 시민리더 담당자 인터뷰에서 "거리(권역) 와 전문분야가 가장 중요하다"는 피드백을 받아
각 40점씩 배정하고, 시간대는 20점으로 두었습니다. 보너스/패널티는 운영 중에 추가된 정책들로,
누적식이어서 100점을 넘어갈 수 있습니다.

### Q3. "강사가 거절하면요?"
**A.** `POST /api/match/<id>/reject` 호출 시 `status='거절'` 로 전이하고
**다음 후보 강사를 응답에 자동 포함**합니다. 또한 ML 학습용으로 거절 사유도 같이 저장합니다.

### Q4. "DB는 뭐 쓰나요?"
**A.** **Supabase(PostgreSQL)** 입니다. 개발 환경에서는 자동으로 SQLite 로 fallback 되어
오프라인에서도 동일하게 작동합니다.

### Q5. "테스트는 얼마나 있나요?"
**A.** **pytest 기반 195개**. 매칭 알고리즘(93) / v4 신규 기능(31) / ML(28) /
세션(26) / 지도(10) / 대시보드(7) 로 구성. CI 환경에서 평균 3~5초 안에 전부 통과합니다.

### Q6. "시연 데이터는 실제 데이터인가요?"
**A.** 화성시 시민리더 사업 공개 자료를 참고해 만든 **현실적인 더미 데이터**입니다 (개인정보 X).
강사 40명 / 기관 30곳 / 요청 60건 / 매칭 300건 규모.

### Q7. "권역명에 '동탄1' 처럼 세부 지역이 들어오면요?"
**A.** `normalize_region()` 으로 자동 정규화합니다. `동탄1` / `동탄` 모두 `동부권` 으로 매핑됩니다.
이건 v4.8 검증 이슈 #3 수정 사항입니다.

### Q8. "강사가 매칭 안 되면 사용자한테 뭐라고 보여주나요?"
**A.** `match_mode` 와 `match_mode_reason` 을 응답에 명시합니다. 5명 미만 매칭이면
`failure_reasons` 도 추가로 반환해 "권역 강사 없음 / 시간대 안 맞음" 같이 구체적 사유를 알려줍니다.

### Q9. "관리자가 직접 등급 올릴 수 있나요?"
**A.** 자동 승급 시스템이 있어 별도 조작은 필요 없습니다. 단, 관리자가 수동 일괄 승급을 트리거하려면
`POST /api/admin/grade-upgrade` (X-Admin-Token 필요) 를 호출하면 됩니다. 모든 변경은
`grade_histories` 에 자동 이력으로 남습니다.

### Q10. "프론트엔드는 누가 만드나요?"
**A.** 본 발표는 백엔드/알고리즘 데모이며, 프론트엔드는 팀장(1번)이 별도로 개발 중입니다.
협업용 API 명세는 [`docs/API_REFERENCE.md`](API_REFERENCE.md) 에 정리되어 있습니다.

## 4. 시연 중 실수 방지 체크리스트

- [ ] **터미널 폰트 크기 키우기** (Ctrl/Cmd + + 로 최소 18pt)
- [ ] **불필요한 알림 끄기** (Slack, Discord, 메신저)
- [ ] **워밍업** — 시연 직전 한 번 더 `--only 1` 로 점검
- [ ] **DB 연결 한 번 더 확인** — 인터넷 끊겨도 SQLite fallback OK
- [ ] **터미널 폭 ≥ 80자** (출력이 깨질 수 있음)
- [ ] **`.env` 의 `ADMIN_TOKEN` 설정 확인** (관리자 시연하는 경우)
- [ ] **백업 캡처 준비** — Supabase 가 느릴 때를 대비한 사전 캡처 슬라이드
- [ ] **질문 받는 자리는 마지막 1~2분** — 시연 중간 끊기지 않게
- [ ] **알고리즘 버전 발음 통일** — "v사점팔" 보다 "v4.8" 로 영문 그대로

## 5. 시연 중 발생 가능한 트러블슈팅

| 증상 | 원인 | 즉시 대응 |
|------|------|----------|
| `find_top_matches` 결과 0건 | 데이터 시드 안 됨 | `python -c "from app.services.seed_data import seed_if_empty; from app import create_app; app=create_app(); app.app_context().push(); seed_if_empty()"` |
| Supabase 응답 느림 | 콜드 스타트 | `.env` 의 `DATABASE_URL` 삭제 → SQLite 자동 fallback |
| `ModuleNotFoundError: app` | 작업 디렉토리 문제 | `cd /home/user/capstone` 후 다시 실행 |
| 신규 강사 슬롯 None | 모든 신규 강사가 Top 5 안에 들어옴 | 정상 동작 — "이번엔 Top 5 안에 들어왔다" 로 설명 |
| `match_mode='최선추천'` | 조건 부합 강사가 전혀 없음 | 정상 동작 — fallback 작동 사례로 활용 |
